# 开发需求文档：微信群 PK 打卡插件

## 简介
本文档基于 `dify-on-wechat` 项目设计的一个微信群 PK 打卡插件。该插件将支持群内打卡任务、积分竞赛和管理员管理功能，旨在好友互相监督打卡,提升群内互动性和活跃度。插件将利用`dify-on-wechat`微信机器人的特性,结合sqllite实现持久化操作，确保功能的完整性和可扩展性。

## 功能需求

### 打卡系统
- **支持多种频率**：管理员可通过指令设置打卡任务的频率（日/周/月）。
- **积分奖励规则**：
  - **首打卡奖励**：群内首次打卡的用户奖励 3 积分，可通过管理员设置启用或禁用。
  - **周打卡奖励**：每周打卡次数最多的用户额外奖励 3 积分，可通过管理员设置启用或禁用。
  - **月打卡奖励**：每月打卡次数最多的用户额外奖励 5 积分，可通过管理员设置启用或禁用。
  - **连续打卡奖励**：用户连续 3 天打卡时，额外奖励 3 积分，可通过管理员设置启用或禁用。
- **打卡操作**：用户通过发送指令 `PKTracker [任务名称] 任务内容` 参与打卡，机器人记录用户 ID、群 ID、打卡时间和可选内容。例如：`PKTracker [健身] 练了一下胸，运动了 60min，感觉不错。`
- **积分奖励**：每成功打卡奖励 1 积分；日频率下，首次打卡用户额外奖励 3 积分（若启用首打卡奖励）。

### PK 竞赛机制
- **积分排名**：通过指令 `PKTracker [任务名称] 积分排名` 展示群内所有用户的打卡详情，包括用户排名、用户名称、打卡次数、总积分、周积分和月积分。
- **激励机制**：通过积分排名和额外奖励增强群内互动。

### 管理员功能
- **频率设置**：管理员通过 `PKTracker 设置频率 [任务名称] [日/周/月]` 指令设置打卡频率。
- **提醒设置**：管理员通过 `PKTracker 设置提醒 [任务名称] [时间]` 设置提醒时间（如每日 20:00），机器人按设定时间发送提醒。
- **排行榜发送**：机器人定期（如每周或每月）发送历史积分排行榜。
- **奖励设置**：管理员通过 `PKTracker [任务名称] [首打卡奖励/周打卡奖励/月打卡奖励/连续打卡奖励] 开/关` 启用或禁用打卡奖励。

### 数据查询
- **个人记录**：用户通过 `PKTracker [任务名称] 打卡记录` 查询个人总打卡次数、总积分和最后打卡时间。
- **群内排名**：用户通过 `PKTracker [任务名称] 排行榜` 查看群内积分排名（显示前 10 名）。

## 技术需求

### 插件结构
- **插件目录**：在 `dify-on-wechat` 的 `plugins` 目录下创建 `PKTracker` 子目录，包含 `__init__.py` 文件。
- **插件类**：定义 `PKTracker` 类，继承自 `Plugin`，使用 `@plugins.register` 注册，设置名称（PKTracker）、描述、版本、作者和优先级（低于 999）。
- **事件处理**：绑定 `ON_HANDLE_CONTEXT` 事件，处理群消息，识别指令并执行对应逻辑。

### 数据库设计

#### t_task (任务表)
| 字段名 | 描述 |
|--------|------|
| task_id | 主键 |
| group_id | 群 ID |
| task_name | 任务名称 |
| frequency | 频率（day/week/month） |
| first_checkin_reward_enabled | 首打卡奖励开关 0/1 |
| first_checkin_reward | 首打卡奖励积分 默认为 3 |
| week_checkin_reward_enabled | 周打卡奖励开关 0/1 |
| week_checkin_reward | 周打卡奖励积分 默认为 3 |
| month_checkin_reward_enabled | 月打卡奖励开关 0/1 |
| month_checkin_reward | 月打卡奖励积分 默认为 3 |
| consecutive_checkin_reward_enabled | 连续打卡奖励开关 0/1 |
| consecutive_checkin_reward | 连续打卡奖励积分 默认为 3 |
| reminder_time | 提醒时间，cron 表达式 |
| enable | 开启/关闭 1/0 |

#### t_checkin_log (打卡记录表)
| 字段名 | 描述 |
|--------|------|
| checkin_id | 主键 |
| task_id | 外键，关联 `t_task` |
| user_id | 用户 ID |
| checkin_time | 打卡时间 `yyyy-MM-dd HH:mm:ss` |
| content | 打卡内容 |

#### t_user (用户表)
| 字段名 | 描述 |
|--------|------|
| user_id | 主键 |
| name | 用户名称 |

#### t_admin (管理员表)
| 字段名 | 描述 |
|--------|------|
| group_id | 群 ID |
| user_id | 管理员用户 ID |

#### t_bonus (积分表)
| 字段名 | 描述 |
|--------|------|
| bonus_id | 主键 |
| task_id | 外键，关联 `t_task` |
| user_id | 用户 ID |
| type | 奖励类型（first_checkin/consecutive/week/month） |
| amount | 奖励积分 |
| date_awarded | 奖励日期 |
